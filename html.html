02 / Conceptos clave

¿Qué es una API REST?

Un servidor que entrega y recibe datos mediante HTTP en formato JSON. Lo usaremos para almacenar y consultar contactos con persistencia real, sin depender de localStorage.

Métodos HTTP que usaremos en la Agenda

GET

Leer datos

Cargar la lista de contactos

POST

Crear datos

Guardar un nuevo contacto

DELETE

Borrar datos

Eliminar un contacto por id

05 / src/api.js

Las 3 funciones de la API

// Base URL de la API local const API = "http://localhost:3001/contactos"; // GET — obtener todos los contactos export async function listarContactos() { const res = await fetch(API); // Si la respuesta no es OK (>=400), lanzamos error if (!res.ok) throw new Error("Error al listar contactos"); return res.json(); // ← devuelve array de contactos }
GET /contactos → 200 OK + [ {…}, {…} ]
// POST — crear un nuevo contacto export async function crearContacto(data) { const res = await fetch(API, { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify(data), // objeto → JSON string }); if (!res.ok) throw new Error("Error al crear el contacto"); return res.json(); // ← contacto creado con id asignado }
POST /contactos → 201 Created + { id, nombre, … }
// DELETE — eliminar contacto por id export async function eliminarContactoPorId(id) { const res = await fetch(`${API}/${id}`, { method: "DELETE", }); if (!res.ok) throw new Error("Error al eliminar el contacto"); return true; // éxito confirmado }
DELETE /contactos/:id → 200 OK — contacto eliminado
06 / App.jsx — Integración

Estados + handlers

// importamos las funciones de api.js import { listarContactos, crearContacto, eliminarContactoPorId } from "./api.js"; // Los 3 estados del componente App const [contactos, setContactos ] = useState([]); // ↑ lista que viene de la API ↑ vacía al inicio const [cargando, setCargando ] = useState(true); // ↑ true mientras esperamos la respuesta const [error, setError ] = useState(""); // ↑ mensaje de error si la API falla
💡

Tres estados, tres responsabilidades claras: datos, carga y error. Esta es la estructura estándar para consumo de APIs en React.

// useEffect — se ejecuta UNA vez al montar el componente useEffect(() => { async function cargarContactos() { try { const data = await listarContactos(); // GET a la API setContactos(data); // guardamos en estado } catch (e) { setError("No se pudo cargar la lista de contactos"); } finally { setCargando(false); // ocultamos el spinner } } cargarContactos(); }, []); // ← [] = solo se ejecuta al montar, no en cada render
GET → setContactos(data) → re-render con la lista
// Agregar contacto — llamado desde FormularioContacto const agregarContacto = async (nuevo) => { try { const creado = await crearContacto(nuevo); // POST // No recargamos toda la lista: añadimos solo el nuevo setContactos((prev) => [...prev, creado]); } catch (e) { setError("No se pudo agregar el contacto"); } };
POST → crearContacto(nuevo) → [...prev, creado]
// Eliminar contacto — llamado desde ContactoCard const eliminarContacto = async (id) => { try { await eliminarContactoPorId(id); // DELETE en la API // Filtramos el estado local sin recargar setContactos((prev) => prev.filter((c) => c.id !== id)); } catch (e) { setError("No se pudo eliminar el contacto"); } };
DELETE → eliminarContactoPorId(id) → filter del estado
07 / Componentes

FormularioContacto & ContactoCard

export default function FormularioContacto({ onAgregar }) { // Estado del formulario como objeto único const [form, setForm] = useState({ nombre: "", telefono: "", correo: "", etiqueta: "" }); // onChange genérico — usa el atributo name del input const onChange = (e) => setForm({ ...form, [e.target.name]: e.target.value }); const onSubmit = (e) => { e.preventDefault(); if (!form.nombre || !form.telefono || !form.correo) return; onAgregar(form); // llama agregarContacto en App.jsx setForm({ nombre: "", telefono: "", correo: "", etiqueta: "" }); }; }
💡

onChange genérico: un solo handler para todos los campos, gracias a [e.target.name] como llave dinámica.

export default function ContactoCard( { nombre, telefono, correo, etiqueta, onEliminar } ) { return ( <div className="bg-white shadow-sm border border-gray-200 rounded-2xl p-6 flex items-start justify-between"> {/* Info del contacto */} <div className="space-y-1"> <h3>{nombre}</h3> <p>📞 {telefono}</p> <p>✉️ {correo}</p> {etiqueta && <span>{etiqueta}</span>} </div> {/* Botón eliminar */} <button onClick={onEliminar}>Eliminar</button> </div> ); }
💡

onEliminar es una función que llega del padre como prop. El componente no sabe nada de la API — solo llama a lo que recibe.
